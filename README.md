# KuniVRCPhotEditor

VRChat写真のメタデータを閲覧・編集し、新しい写真へ同室者情報やOCRによるモデル候補を記録するWindows用アプリです。本体は **v0.6.12**。Stableの配布版はファイル名の版番号を確認してください。

## 動作環境・起動

Windows 10 1903以降／Windows 11のx64に対応します。Stable配下の配布ファイルを取得し、ZIPの場合は展開してください。版付きの `KuniVRCPhotEditor_vN.M.X.exe` を、書込み可能なフォルダーへ置いて起動します。設定はEXE配下のData/settings.json、キャッシュ等もData配下へ保存します。旧保存先は初回起動時に移行します。Releaseは追加のWebPコーデックや専用DLLなしで動作します。OCRには利用可能なWindowsの言語モデルが必要です。

配布時は `THIRD_PARTY_NOTICES.md`、`libwebp-COPYING.txt`、`libwebp-PATENTS.txt` を同梱してください。ライセンスは［ヘルプ］→［ライセンス情報］でも確認できます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 写真閲覧 | PNG／JPEG／WebPのサムネイル、プレビュー、Windowsフォト起動 |
| メタデータ編集 | 撮影日時・撮影者・ワールド・モデル・タグの表示／編集、複数画像の一括編集 |
| 整理・検索 | ファイル名／メタデータ検索、並べ替え、フォルダー履歴・ブックマーク |
| MDB | メタデータのローカルキャッシュ、人物・タグ・ワールド等の分類と折り畳み、人物の優先表示、IDと表示名の対応表 |
| 自動記録 | VRChatログから同室者・不足するワールド情報等を新規写真へ記録 |
| 観測 | VRChatログの入退室・ワールド移動・動画URLを表示・保存。初期オフ、標準10秒／高2秒更新。折り返し・標準／ナイト別の文字色設定に対応 |
| OCR | 画面内の名前を参加者と照合し、モデル候補を記録。画像・他ウィンドウでのテストにも対応 |
| キャッシュ設定 | メモリ・ディスク・MDBと観測ログの容量／使用率を一覧確認。メモリ・ディスク・MDBの有効切替、無効化時の保存分保持 |
| 表示・保存 | タイル表示、ライト／ダーク、背景画像と画像別テーマ、フォント設定、サイドビュー、バックアップ |

## 写真を開く・表示する

1. ［フォルダー］で写真フォルダーを選び、更新アイコンの［ロード］で一覧を読み込みます。直下の画像とサブフォルダーが表示されます。
2. 写真を選び、［シンプル］／［詳細］でメタデータを確認します。Ctrl＋ホイールで一覧サイズを変えられます。
3. ［詳細］の［編集］から変更し、上書きまたは別名コピーで保存します。複数選択時は一括編集できます。

検索は［検索］または検索欄のEnterで実行します。サブフォルダー内は検索しません。［ファイル名省略］をONにすると正方形タイル表示になります。操作・設定値・保存条件は[利用ガイド](Documents/USER_GUIDE.md)を参照してください。

## キャッシュ設定

［オプション］の［画像サムネイルキャッシュ上限］［ディスクキャッシュ］［MDB設定］は、共通の［キャッシュ設定］を開き、呼び出し元の項目を選択表示します。メモリ・ディスク・MDBの有効／無効と容量、観測ログの容量を設定でき、現在使用量／設定容量・使用率を一覧で確認できます。MDBの無制限では使用率を表示しません。画面は拡縮でき、狭い場合は縦スクロールで設定項目を表示します。

観測ログは初期10 MBで、容量超過時は古いイベントから整理します。開始・停止は［観測］タブで選択します。表示の折り返し、ナイトモードの黒背景、［フォント］での文字色設定は[観測の使い方](Documents/USER_GUIDE.md#観測)を参照してください。

［ブックマーク］→［キャッシュする］で、表示中フォルダー直下の画像をファイル名順に、有効な各キャッシュの空き容量へ追加します。既存の保持項目を残し、保持件数や未保持の有無を通知します。サブフォルダーは対象外です。

無効化の適用時は「保存済みのキャッシュは自動削除されません」と通知します。ディスクとMDBは保存分を保持し、再有効化すると利用できます。メモリは再利用用の領域を解放し、一覧表示用の領域を保持します。保存条件や容量整理は[利用ガイド](Documents/USER_GUIDE.md#オプション注意点)を参照してください。

## 人物記録・OCR

VRChatの［設定］→［Debug］→［Logging］を **Full**、カメラの **Save MetadataをON** にします。［オプション］→［記録設定］でログ／写真フォルダーを確認し、［記録開始］を押すと、新規PNG／JPEGへ情報を追記します。既存写真は自動変更しません。

［常駐モード］をONにするとVRChatの起動／終了に連動します。［常駐OCR］は次の記録開始からOCRを併用する設定です。ともに初期OFFです。ユーザーID保存は初期OFF、グループID保存は初期ONです。

## 注意点

- 自動記録は写真への上書きとAB_バックアップを伴います。手動上書きの自動バックアップも初期ONです。保存条件・上限整理は[バックアップ](Documents/USER_GUIDE.md#バックアップ)を確認してください。
- 同室者は写真に写った人物の確定一覧ではありません。OCR候補も推測で、距離・傾斜・見切れ・背景などに左右されます。実用性の評価は十分でなく、精度の追加改善は終了しています。共有前に人物情報・ID等の記録を確認してください。
- **本アプリではWindowsフォトによる同一ディレクトリ内の画像移動は実装していません。** 別画像は本アプリの一覧で選び直してください。
- MDBは初期OFFで、メタデータをローカルに保持し、外部送信しません。OFF適用後も保存済みDBを保持します。独立したID・表示名対応表は残ります。画像から対応表へ反映する操作は、確認後にバックアップなしで既存名も上書きします。
- EXIF回転・ICC色管理・DPI調整等には未対応事項があります。別PC・大量実写真の性能を含む[対応範囲と注意](Documents/USER_GUIDE.md#オプション注意点)を参照してください。
