# v0.3.0 メタデータ編集・保存

v0.3.1では上書き保存と自動バックアップを追加。現在の操作・保存方針は [README](README.md) を参照。v0.3.5の複数編集・タグ・WebP対応は [V0.3.5_PLAN.md](V0.3.5_PLAN.md) を参照。以下はv0.3.0実装の基準。

Stage2の実装方針。実写真のタグ対応と配布の確認は継続する。

## 編集対象

| 入力 | XMP項目 | 保存ルール |
|---|---|---|
| 撮影日時 | xmp:CreateDate | 有効なXMP日時。推測日時は自動入力・保存しない |
| 撮影者 | xmp:Author | 既存ビューアーと同じ項目 |
| ワールド名 | vrc:WorldDisplayName | 既存ビューアーと同じ項目 |
| ワールドID | vrc:WorldID | 設定時はwrld_＋UUIDを検証 |
| 被写体名一覧 | kpe:Subjects / rdf:Seq | 1行1名。ユーザー指定のアプリ独自タグ |

xmpは `http://ns.adobe.com/xap/1.0/`、vrcは `http://ns.vrchat.com/vrc/1.0/`、kpeは `urn:kunivrcphoteditor:metadata:1.0`。EXIFの日時等は変更せず、表示はXMPを優先する。標準・拡張に重複する編集対象は両方から除き、設定値を標準側へ追加する。その他の情報は保持する。

## 操作と保存

詳細タブで編集を開始する。入力変更は「値を設定」として扱い、「変更しない」「値を削除する」も指定できる。空欄を削除と解釈しない。日時・ID・文字の検証に失敗した場合は保存を無効にする。キャンセルは編集を破棄して閲覧へ戻る。

保存ダイアログの既定名は元の名前＋ `_edited`。PNG/JPEGのみ別名コピーへ保存し、原本・既存保存先を上書きしない。WebPは閲覧のみ。未保存の切替・終了は保存／破棄／キャンセルを選び、保存失敗・保存先選択キャンセルでは編集を保持する。保存中は切替と多重保存を禁止する。

Windows標準のMSXML6と既存のXMP解析・Extended XMP復元を使用する。追加の配布DLL・書込みライブラリは不要。PNGのXMPチャンク、JPEGのXMP APP1だけを再構成し、画像・EXIF・ICC・その他のチャンク/セグメントはバイト単位で保持する。画素を再圧縮しない。未知XMLは編集対象を除いたDOMの比較で保持を検証する。

一時コピーの再読込み・編集値・保持データを検証後、既存先を置換しない移動で確定する。原本は保存中に書込み・削除を共有せず、編集時の指紋とも照合する。失敗時は一時ファイルを除去し、完成扱いしない。成功後は保存先フォルダーを読み直し、コピーを選択する。

## 制限・検証範囲

- 入力画像256MiB、標準＋拡張XMP16MiB、入力各項目65536文字まで。圧縮PNG XMP、複数標準XMP、不正XML、壊れた/未参照のExtended XMP、未対応のRDF構造は保存せず通知する。
- 同時に大きな標準・拡張XMPが存在し、標準をAPP1へ収められない場合も保存を中止する。安全に保持できる構造を汎用RDF統合で推測しない。
- サムネイルの画素を独立コピーして即時プレビューへ渡す。メタデータ解析と通知は別で、キャッシュの除外後も選択プレビューは保持される。プレビューはサムネイル解像度で、高解像度を再デコードしない。
- プレビューのダブルクリックは一覧と同じWindowsフォト起動経路を使う。編集中は保存済み画像を渡し、未保存内容が反映されない旨を通知する。
- 合成PNG/JPEG・透明PNG・Extended XMPで原本不変、画素一致、未知データ保持、保存拒否を確認。UI試験で500msの解析遅延、未保存切替、保存失敗と再表示、フォトへの要求パスを確認する。実写真・ネイティブ保存ダイアログの実操作・容量不足・別PC配布は別途確認する。
