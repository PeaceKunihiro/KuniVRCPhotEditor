# v0.4.22 WebP XMP末尾NULの互換対応

実装日: 2026-10-13（日本時間）。[調査結果](XNCONVERT_WEBP_XMP_INVESTIGATION.md)に基づき、XnConvert変換サンプルで見つかったXMP末尾NULによる表示・編集拒否へ対応した。

## 対応範囲

WebPのXMPがUTF-8として有効で、末尾にのみNULが付いている場合、その末尾NULを除いた解析用データを表示・編集DOMで共通使用する。1個／複数に対応し、通常のXML検証を通過したデータだけを採用する。シンプル表示に加え、編集の既存値読込み・別名コピー・上書き・AB_作成でも利用する。

読込みでは画像ファイルを書き換えない。表示ノートには末尾NULを除いた解析用データで読んだ旨を添える。ファイルの原本指紋・保持チャンクは元のバイトを使用し、保存するときだけ編集後のXMLを出力する。

本文中のNUL、不正UTF-8／XML、DTD、サイズ上限超過は引き続き拒否する。元のXMP長で上限を確認してから正規化する。UTF-16／32のバイトをUTF-8終端として削らず、PNG／JPEGの入力には適用しない。画像再圧縮・メタデータ移行・一括修復を自動実行する機能は追加しない。

## 検証

最終Debug／Release x64の `build.cmd Debug Test`／`build.cmd Release Test` は終了コード0、全自己・UI試験成功、各20回即時終了試験成功。両構成で提供PNG／WebP8組の読取りと専用コピー編集も成功。試験の書込みは各EXE配下のself-test-dataへ限定し、提供サンプルは未変更。ログは `x64/Debug/v0422-build-test.log`／`x64/Release/v0422-build-test.log`。生成画面でもシンプル表示を確認した。

- 合成WebP：NULなし／末尾1〜3個、シンプル値・同名人物のID対応・モデル候補、別名コピーの未知XML／チャンク／画像保持、原本不変を確認。
- 上書きと自動バックアップ：編集前の項目／人物情報と【AutoBackup】タグ、管理記録の原本指紋を確認。
- 異常系：本文内NUL、壊れたXML、DTD、不正UTF-8、過大XMPの拒否、UTF-16への非適用、PNG／JPEGの末尾NULが従来どおり解析エラーとなることを確認。
- 提供された8組：PNGとWebPのシンプル用値が一致し、WebPを元に専用コピーを編集しても人物情報・画像を保持し、元WebPの指紋が変わらないことを確認。任意の追加試験は `KUNI_WEBP_TEST_SAMPLES` 環境変数で明示したフォルダーだけを読む。通常の自己試験は実写真に依存しない。
- UI：末尾NUL付きWebPのシンプル欄に撮影者／同室者を表示し、編集欄へ既存撮影者を読み込むことを確認。

未知XML保持・書込み後検証・原本変更検出・バックアップ失敗時の中止は従来どおり。提供サンプルの実操作、一括変換の別条件、他ソフトの出力は未検証。
