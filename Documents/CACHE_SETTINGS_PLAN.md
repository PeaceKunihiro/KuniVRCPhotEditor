# キャッシュ設定ダイアログ統合仕様（v0.6.6）

ディスクキャッシュ、サムネイルキャッシュ（メモリ）、MDBの有効状態・容量上限・使用量と使用率を一画面に表示する。各行のチェックボックスで有効／無効を選択する。従来の3つの呼び出し項目を維持し、開いたときに対応する行を強調表示してフォーカスを置く。

有効だった項目を無効にして［適用］したとき、「保存済みのキャッシュは自動削除されません」と通知する。複数項目をまとめて無効にした場合は対象名を添えて一度だけ通知する。［キャンセル］した場合や、適用前に有効へ戻した場合は通知しない。

ディスク上のサムネイルとMDBは無効化後も保持する。このため、実装時には現行のMDBの無効化に伴う自動削除を廃止する。メモリ上のサムネイルは一時データであり、無効化時に再利用用の領域を解放し、一覧表示に必要な領域は維持する。
