### 改修内容

- 画像一覧の項目間隔を横「幅＋36px」から「幅＋8px」、縦「高さ＋44px」から「高さ＋フォント1行＋8px」へ縮小。既定幅128pxではこの環境で164×140px→136×116px。起動・Ctrlホイール変更で共通処理を使用。

- ウィンドウ拡縮時に上部ボタンの旧描画が残る問題を修正。上部コントロールを一括配置し、移動時の旧画素コピーを抑止。背景と子コントロールを再描画し、親の背景描画が子コントロールを上書きしないよう変更。
- 「開く」「再読込み」を「ロード」に統合。Enterも同じ動作。入力アドレスが現在と同じフォルダーならキャッシュをクリアして再読込みし、存在する選択画像を保持。別のアドレスなら切替、無効・空欄では一覧を保持。
- 「オプション ▼」を追加。サムネイルキャッシュ上限は初期100MB（10進）、16〜2048MBの整数で設定し、起動中に反映・保存。
- キャッシュ上限をLRUの画像データとImageListの画像・マスクの実ビットマップ保持量の合計へ適用。サムネイル幅と予算からスロット数を計算し、変更時に一覧を再構成。画面内の件数が保持予算を超える場合は一部をプレースホルダーとし、状態欄に表示。デコード・プレビュー・待機結果・管理領域を含むアプリ全体の上限ではない。

- 「ブックマーク ▼」内にアドレス追加・登録先ロード・削除サブメニューを追加。追加だけではロードせず、同じ実在フォルダーの重複を防ぐ。開けなくなった登録先を自動削除しない。履歴保存OFFでも独立して保存。上限1000件。
- settings.jsonをversion=2へ更新し、version=1も読込み可能。追加項目のない旧設定は100MB・履歴ON・ブックマークなし。設定復元時は保存先フォルダーを一件ずつ実在検証しない。
- JPEG Extended XMP対応。標準のHasExtendedXMPを名前空間URIで取得し、参照GUIDに一致する分割APP1をオフセット順に復元。全体長・欠落・重複・重なり・範囲超過・MD5・XMLを検証。標準＋拡張のXMP上限16MiB、拡張収集1024件まで。
- 拡張の破損時は読める標準XMPを保持。拡張で既存のシンプル項目を補完し、標準側と矛盾する項目は標準を優先して詳細に通知。取得したXMLも詳細へ表示。汎用RDF全構造の統合や画像への書込みは追加しない。
- 上部2段の配置を更新し、最小ウィンドウ幅でも履歴・ブックマーク・オプション・配置選択が重ならないよう調整。

- 作成日時をxmp:CreateDate → 指定形式のVRChatファイル名からの推測 → ファイル作成日時 → ファイル更新日時の順で取得し、取得元を併記。XMPのタイムゾーン・サブ秒を保持。
- ファイル名はVRChat-YYYY-MM-DD-hh-mm-ss.microSec_WidthxHightを厳密に判定。サブ秒1〜6桁、実在する日付・時刻、正の幅・高さを検証し、不正ならファイル日時にフォールバック。
- xmp:Author、vrc:WorldDisplayName、vrc:WorldIDを表示。欠落時は空欄。モデルは将来の被写体名表示用として空欄。
- PNGの非圧縮iTXt / tEXtに格納されたXMPとJPEGの標準APP1 XMPを直接抽出。名前空間URIと項目名で照合し、接頭辞変更、属性、要素、配列、日本語、XMLエンティティを扱う。
- XMPの直接抽出結果と解析状況を詳細タブにも追加。XML解析失敗・不正日時・PNG XMPのCRC不一致を区別し、原本には書き込まない。
- 両タブを同一の非同期読込み結果から更新し、タブ切替で再読込みしない。選択変更時は両方の古い情報をクリア。

### 確認結果・制限

- Debug / x64、Release / x64のビルドと--self-test / --ui-test成功。
- 合成PNG/JPEGでXMP4項目、日時優先順位、うるう年・不正日時、ファイル名形式、欠落時空欄、作成日時フォールバックを確認。
- 各配置での列位置、長い日本語の折返し、最終モデル欄までのスクロール、タブ切替時の情報保持を自動確認。v0.1.1の一覧リサイズ・Ctrlホイール・選択保持・再読込みの自動確認も成功。
- PNGの圧縮XMP（zTXt / 圧縮iTXt）、JPEG Extended XMPは直接抽出の対象外。検出した場合は未対応として表示。EXIFの完全対応、実際のVRChat写真でのXMP検証、新UIの目視確認は引き続き必要。

## v0.1.0 — 2026-10-09

画像メタデータビューアーの初期開発版。VIEWER_REQUIREMENTS.mdに基づく第1段階の実装を開始しました。全要件を満たした完成版ではありません。

### 実装した機能

- フォルダー選択ダイアログ、パス直接入力、履歴から画像フォルダーを開く機能。
- 最後に開いたフォルダーの復元、重複を除いた直近10件のフォルダー履歴。
- PNG / JPEG（.png / .jpg / .jpeg）のサムネイルとファイル名一覧。拡張子の大文字・小文字を区別せず、ファイル名昇順で表示。サブフォルダーは対象外。
- 縦横比を保持したサムネイルと画像プレビュー。
- 画像選択時のファイル名、フルパス、形式、ファイルサイズ、幅・高さ、ファイル更新日時の表示。
- Windows Imaging Component（WIC）で取得可能なメタデータの階層付きタグ・値表示。長い値はスクロールして閲覧可能。
- サイドビューの右・左・下への配置切替。
- プレビュー上のマウスホイールによる前後の画像切替。先頭・末尾で停止し、選択サムネイルを一覧内に表示。
- 再読込みによる一覧更新。選択ファイルが残っている場合は選択を維持し、削除されている場合は解除。
- 空フォルダーの案内、破損画像の代替表示・読込みエラー表示、無効フォルダー入力時の現在の一覧保持。
- ワーカースレッドによる画像読込み。フォルダー・選択の世代判定により古い非同期結果を除外する処理。

### 設定・開発環境

- EXEと同じフォルダーのsettings.jsonに設定バージョン、最後のフォルダー、履歴、サイドビュー配置を保存。
- 設定保存失敗を通知。壊れた設定は元ファイルを保全し、初期値で起動。その起動中は設定保存を停止。
- 原本画像は読取り専用で開き、画像・メタデータの編集や書込みは行わない実装。
- Visual Studio 2022 / C++17 / Win32 / Unicode / UTF-8を使用。
- Debug / x64とRelease / x64のビルド構成。CRTは静的リンク（Debug: /MTd、Release: /MT）。
- ビルド補助のbuild.cmd、操作・制限を説明するREADME.md、引継ぎ用KuniVRCPhotEditor_workを整備。
- --self-testで画像読込み・設定JSON等を確認できる自動確認モードを追加。
