# v0.5.3 正方形タイル・記録ボタン説明の実装と検証

2026-10-17（日本時間）。[実装案](V0.5.3_PLAN.md)の採用指示に基づく。

## 実装

- ［ファイル名省略］ONを中央切抜きの正方形タイルへ接続。縦横比を維持して枠を埋め、画像間隔を2pxにする。OFFでは4:3枠内の画像全体と省略名表示へ戻る。フォルダーはアイコン内の名前を保持し、画像には完全名のツールチップと選択枠を残す。
- ImageListの高さ・メモリー見積り・保持枠数・行間・自動サイズ計算を正方形へ対応。切替時はImageListを再作成して表示世代を更新し、選択・フォーカス・編集中の状態を保持する。フォーカス項目があれば表示を維持し、なければスクロール位置を可能な範囲で復元する。
- 切抜きは表示用ビットマップだけへ適用。キャッシュは元の縦横比を保った最大256×256の基礎画像とし、ディスクキーを256x256/v2へ変更する。読込み側・書込み側の高さ／バイト上限も256に整合させ、旧256x192/v1を新しい仕様として使わない。原画像・独立した選択プレビュー・OCR入力は変更しない。
- 記録ボタン専用ツールチップを生成し、初回と再表示の待ち時間をともに3,000msへ設定。停止中は「写真へ追加情報の記録を開始します」、記録中は「写真へ追加情報の記録を停止します」を表示する。
- 記録状態や操作可否が変わった時だけ旧説明を閉じて更新。500ms周期では無条件更新せず、停止処理中・親画面がモーダルで無効の場合は抑止する。説明表示で記録開始／停止・写真書込みは行わない。他のボタンのツールチップは変更しない。

## 検証

- Debug／Release x64のビルド、全自己・UI試験、各3回の即時終了試験は成功（終了コード0）。Debugの全体試験後に自己試験開始時の表示設定だけを固定し、自己試験のみ再確認した。全体UI試験の不要な再実行はしていない。両EXEのFileVersion 0.5.3.0と版付きOriginalFilename、VS Debugの版付き起動先を確認した。
- 合成した横長・縦長・正方形のピクセルで中央切抜きと正方形キャンバスを確認。専用PNG一覧で128px正方形・130px間隔、通常表示への復帰、選択と編集状態の保持、原本指紋と全体プレビューの不変、旧表示世代の排除を確認した。
- 左／右／下／なし、自動サイズ、16MBのメモリー設定を確認。256×256のディスク保存・再読込みと旧キーとの分離を確認した。v0.5.0の行間試験は「名前なしでも4:3枠」の旧前提を、新しい正方形セルの間隔確認へ更新した。
- ツールチップの初回／再表示設定が3,000msであること、停止／記録の指定文、操作不可時の空表示を実記録なしで確認した。実カーソルの3秒待ち・離脱／再侵入と実VRChat記録中の表示は未検証。
- v053-tiles-light.png／v053-tiles-night.pngで密な配置と選択枠を目視確認。通常の試験書込み先は各EXE配下self-test-dataのみ。ユーザー原画像・本番設定・実フォト起動は変更／実行していない。
- ログは各x64/<構成>/v053-build.log／v053-test.log、限定試験はself-test-data/tile-tooltip-result.txt。専用入口は--tile-tooltip-test。

## 制約・残る確認

タイルでは端の被写体が見えなくなる場合がある。画像全体はサイドプレビューまたは通常表示で確認する。低解像度の基礎サムネイルを切り抜いて拡大するため、一覧の細部は原寸画像の画質を保証しない。大量の実写真・DPI／高コントラスト・実機の矩形／Shift選択やホバー操作は別途確認する。

Stable差替え、commit／push／tag／公開は行っていない。
