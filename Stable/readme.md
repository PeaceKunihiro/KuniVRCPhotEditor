# KuniVRCPhotEditor の使い方

Windows x64用。EXEとライセンス通知を、書込み可能な場所へ置いて起動します。
[概要](../README.md) ｜ [詳細手順](../Documents/USER_GUIDE.md) ｜ [更新履歴](../Documents/UPDATELOG.md)

## 写真を見る・編集する

［フォルダー］で写真フォルダーを選び、更新アイコンの［ロード］で読み込みます。写真を選ぶと［シンプル］／［詳細］に情報を表示します。［詳細］の［編集］からPNG／JPEG／WebPを編集・保存できます。Ctrl／Shiftで複数選択、Ctrl＋ホイールで一覧を拡縮します。検索はボタンまたは検索欄のEnterで実行し、サブフォルダー内は検索しません。

## VRChatの記録・OCR

VRChatの［設定］→［Debug］→［Logging］をFullにします。Errors Only／Offでは参加者情報を取得できません。カメラのSave MetadataをONにし、本アプリの［オプション］→［記録設定］でログ／写真フォルダーを確認して［記録開始］を押します。新規PNG／JPEGへ上書きし、必ずAB_バックアップを作ります。既存写真は変更しません。

［常駐モード］ONでVRChatの起動／終了に連動します。［常駐OCR］ONで次の記録開始からOCRを併用します。ともに初期OFFです。OCRには画面内のネームプレートとWindows言語モデルが必要です。［OCR］タブでは選択画像や他ウィンドウでもテストできます。距離・傾斜・背景等で認識できない場合があり、候補は推測です。共有前に人物情報・IDを確認してください。

## 注意

手動上書きのバックアップも初期ONです。本アプリではWindowsフォトによる同一ディレクトリ内の画像移動は未実装です。別画像は一覧で選び直してください。最小化すると通知領域へ入り、クリックで復帰します。
