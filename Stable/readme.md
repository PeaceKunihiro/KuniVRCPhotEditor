# KuniVRCPhotEditor の使い方
v0.4.8の手順です。旧EXEでは一部機能がありません。Windows x64用。EXEとライセンス通知を書込み可能なフォルダーへ置いて起動します。

## 写真を見る
[フォルダー]で Pictures\VRChat の年月フォルダーを選び[ロード]。画像を選び[シンプル]／[詳細]で情報を確認します。[検索]または検索欄のEnterで絞り込みます。サブフォルダーは検索しません。Ctrl＋ホイールでサムネイルを拡縮できます。

## VRChat・OCRの準備
カメラの[Save Metadata]をONにします。人物記録には参加者イベントを含むログ、OCRにはPC画面内のネームプレートとWindows OCR言語モデルが必要です。
[人物記録設定]でログ／写真フォルダーを確認し保存します。VRChatと対応ログの検出後に自動開始します。手動停止後は[記録開始]で再開します。ユーザーID保存は既定OFF、グループID保存は既定ON。変更は次の記録開始から適用し、既存情報は削除しません。

[OCR]タブは初期[撮影時OCR]・5FPS・10秒。[設定を適用]で変更し、プレビューと認識／名前の結果を確認します。[テストキャプチャ]は他ウィンドウ、[画像認識]は選択画像を認識します。画像認識は実行／停止・1FPS固定。テストは保存しません。
F12利用時は設定の[F12／日時なし画像フォルダー]に保存先を指定します。写真先と同じ場所も使えます。

新規PNG/JPEGへ上書きし、必ずAB_バックアップを作成します。既存画像は対象外、連写後続は同室者のみです。ワールド名／IDは空欄だけ補完します。グループタグは[シンプル]のボタンから公式ページを開けます。候補は推測で、距離・画面外・ネームプレート背景で認識差があります。共有前に人物情報を確認してください。

[ヘルプ]→[アップデートを確認]で新版をダウンロードできます。終了後の差替えは手動です。詳しくは[機能・注意点](../Documents/README.md)を参照してください。
