# KuniVRCPhotEditor の使い方
Windows x64用。EXEとライセンス通知は書込み可能な場所へ。

[詳細](../README.md) ｜ [更新履歴](../Documents/UPDATELOG.md)

## 写真を見る・編集する
[フォルダー]で Pictures\VRChat の年月フォルダーを選び[ロード]。[シンプル]／[詳細]で情報確認。[検索]または検索欄Enterで絞り込み（サブフォルダー除外）。Ctrl＋ホイールで拡縮。[リセット]で閲覧解除（履歴保持・記録継続）。PNG/JPEG/WebPは編集・上書き／コピー保存可。[並べ替え]で名前／作成日順へ。ID・同室者名の左の↗で公式ページへ。

## VRChat・OCR
人物記録にはクイックメニュー→[設定]→[Debug]→[Logging]を[Full]にします。[Errors Only]／[Off]では参加者情報を取得できません。
VRChatカメラの[Save Metadata]をONにし、[オプション]→[記録設定]でログ／写真フォルダーを確認します。[記録開始]で同室者等を記録。[常駐モード]ONならVRChat起動／終了に連動します。[常駐OCR]ONなら次の記録開始からOCRを併用。初期OFF。ID保存はユーザーOFF／グループON。

OCRは画面内のネームプレートとWindows言語モデルが必要です。[OCR]は撮影時・5FPS・10秒。[設定を適用]で変更し、認識／名前の結果を確認。[テストキャプチャ]は他ウィンドウ、[画像認識]は選択画像（実行／停止・1FPS）。テストは保存せず、ダブルクリックでフォトを開けます。[高精度]は高負荷で改善は限定的です。
F12保存先は[F12／日時なし画像フォルダー]へ。新規PNG/JPEGへ上書きし必ずAB_（タグ【AutoBackup】）を作成。既存画像は除外、連写後続は同室者のみ。候補は推測です。共有前に確認。

最小化で通知領域へ。記録中は赤い印、クリックで復帰、右クリックで終了等。[ディスクキャッシュ]は初期OFF、EXE配下へ保存。[ヘルプ]で使い方・更新を確認。

## zip版
標準機能で解凍できない場合は7zipかEXE版を使います。
