# KuniVRCPhotEditor の使い方
以下はv0.4.5の手順です。旧EXEでは一部項目がありません。Windows x64用。EXEとライセンス通知を書込み可能なフォルダーへ置いて起動します。

## 写真を見る
[フォルダー]で Pictures\VRChat 内の年月フォルダーを選び[ロード]。画像を選ぶと[シンプル]／[詳細]で情報を確認できます。[検索]または検索欄のEnterで絞り込みます。一覧はサブフォルダーを含みません。Ctrl＋ホイールでサムネイルを拡縮すると手動サイズへ切り替わります。自動化は[オプション]で戻せます。

## VRChatの準備
カメラの[Save Metadata]をONにします。撮影者・ワールド情報用で、他の参加者名は保存されません。Private公開ワールドではワールド情報を保存しません。人物記録には参加者イベントを含むログ、OCRにはPC画面に映るネームプレートとWindows OCR言語モデルが必要です。

## OCR・人物記録
[人物記録設定]でログ／写真フォルダーを確認します。自動開始は既定ON。VRChatと対応ログを確認後に記録します。手動停止後は[記録開始]で再開してください。
[OCR]タブの初期設定は[撮影時OCR]・5FPS・10秒。[設定を適用]で変更し、取得プレビューと[OCR結果：認識／名前]を確認します。
テストには対象プルダウンの[テストキャプチャ]で他ウィンドウを選ぶか、[画像認識]で一覧の単体選択画像を認識します。テストは保存しません。
F12利用時は[人物記録設定]の[F12／日時なし画像フォルダー]に保存先を指定します。写真フォルダーと同じ場所も指定できます。

新規PNG/JPEGへ上書きし、必ずAB_バックアップを作成します。既存画像は対象外。連写後続は同室者のみです。候補は推測で、距離・画面外・背景によって認識差があります。写真共有時は人物情報も確認してください。

詳しくは[機能・注意点](../Documents/README.md)を参照してください。
