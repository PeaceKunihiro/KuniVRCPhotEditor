# KuniVRCPhotEditor の使い方
v0.4.12／Windows x64。EXEとライセンス通知を書込み可能なフォルダーへ置きます。

## 写真を見る・編集する
[フォルダー]で Pictures\VRChat の年月フォルダーを選び[ロード]。[シンプル]／[詳細]で情報を確認します。シンプルの空項目は折りたたみます。[検索]または検索欄Enterで絞り込み（サブフォルダー除外）。Ctrl＋ホイールでサムネイルを拡縮。[リセット]で閲覧を解除します（履歴保持・記録継続）。PNG/JPEG/WebPはメタデータ編集・上書き／コピー保存に対応します。

## VRChat・OCRの準備
VRChatカメラの[Save Metadata]をONにします。[オプション]→[記録設定]でログ／写真フォルダーを確認・保存します。VRChatと対応ログの検出後に自動開始。手動停止後は[記録開始]で再開します。ユーザーID保存は既定OFF、グループID保存はON。変更は次の記録開始から適用します。

OCRには画面内のネームプレートとWindows OCR言語モデルが必要です。[OCR]は初期[撮影時OCR]・5FPS・10秒。[設定を適用]で変更し、認識／名前の結果を確認します。[テストキャプチャ]は他ウィンドウ、[画像認識]は選択画像（実行／停止・1FPS固定）。テストは保存しません。[高精度]は原寸タイル認識（既定OFF・高負荷）、容量で保持期間が短くなります。精度改善は限定的です。
F12は設定の[F12／日時なし画像フォルダー]に保存先を指定（写真先と同じ場所も可）。新規PNG/JPEGへ上書きし必ずAB_バックアップを作成。既存画像は対象外、連写後続は同室者のみ。ワールド名／IDは空欄だけ補完します。候補は推測です。共有前に人物情報を確認してください。

[オプション]→[ディスクキャッシュ]は既定OFF。30分内5回ロードしたフォルダーのサムネイルをEXE配下に保存。初期512MiB、最小128MiB。設定画面から削除できます。
[ヘルプ]で使い方・版番号・更新を確認。新版のダウンロード後の差替えは手動です。詳しくは[機能・注意点](../Documents/README.md)。
