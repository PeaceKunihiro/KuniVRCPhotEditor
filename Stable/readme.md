# KuniVRCPhotEditor の使い方
v0.4.13／Windows x64。EXEとライセンス通知を書込み可能な場所へ置きます。

## 写真を見る・編集する
[フォルダー]で Pictures\VRChat の年月フォルダーを選び[ロード]。[シンプル]／[詳細]で情報を確認し、空項目は折りたたみます。[検索]または検索欄Enterで絞り込み（サブフォルダー除外）。Ctrl＋ホイールでサムネイル拡縮。[リセット]で閲覧解除（履歴保持・記録継続）。PNG/JPEG/WebPを編集・上書き／コピー保存できます。

## VRChat・OCR
VRChatカメラの[Save Metadata]をONにし、[オプション]→[記録設定]でログ／写真フォルダーを確認します。[記録開始]で同室者等を記録。[常駐モード]ONならVRChat起動／終了に連動します。[常駐OCR]ONなら次の記録開始からOCRを併用。両方初期OFFで、旧自動開始設定は移行しません。手動停止後は次のVRChat起動か手動開始で再開します。ユーザーID保存はOFF、グループIDはON。

OCRは画面内のネームプレートとWindows言語モデルが必要です。[OCR]は撮影時・5FPS・10秒。[設定を適用]で変更し、認識／名前の結果を確認。[テストキャプチャ]は他ウィンドウ、[画像認識]は選択画像（実行／停止・1FPS）。テストは保存せず、ダブルクリックでフォトを開けます。[高精度]は高負荷で改善は限定的です。
F12保存先は[F12／日時なし画像フォルダー]へ。新規PNG/JPEGへ上書きし必ずAB_を作成。既存画像は除外、連写後続は同室者のみ。候補は推測なので共有前に確認してください。

最小化で通知領域へ。記録中は赤い印、クリックで復帰、右クリックで終了等。[ディスクキャッシュ]は初期OFF、EXE配下へ保存。[ヘルプ]で使い方・版・更新を確認。差替えは手動。[詳細](../Documents/README.md)。

## zip版
7zip梱包のため標準機能で解凍できない場合は7zipかEXE版を使います。
