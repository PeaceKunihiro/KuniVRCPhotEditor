# KuniVRCPhotEditor 引継ぎ

最終更新: 2026-11-28（日本時間）

## 恒久的な指示

- 名称はKuniVRCPhotEditor。Visual Studio 2022 / C++で開発し、VS操作案内は具体的にする。要件正本は [VIEWER_REQUIREMENTS.md](../Documents/VIEWER_REQUIREMENTS.md)、段階仕様はDocuments内Stage1〜Stage5。Stage5はv0.5.6として実装済み。追加着手はユーザー指示に従う。
- このworkは恒久指示・現在地・未解決／未検証・次の作業に限定する。日付ごとの変更・試験・重要な判断は [history](KuniVRCPhotEditor_history.md) に追記し、整理時に失わない。予定・実装・試験済みを区別し、再開時は実ファイルと照合する。ソースから容易に再取得できる情報を重複転記しない。
- 手動編集はPNG/JPEG/WebPの上書き／コピー保存。手動自動バックアップは既定ON、初期上限10。Stage3自動記録ではAB_バックアップを必須として撮影元へ上書きし、既存の命名・同一フォルダー・管理記録・上限を再利用する。バックアップ作成・検証・管理記録保存に失敗したら置換しない。上限整理は管理記録と内容が一致するAB_に限定、手動削除は確認されたチェック対象をごみ箱へ移す。ごみ箱不可時に完全削除しない。
- 設定と管理記録はEXE配下に保存し、壊れたものを保全する。ディスクサムネイルキャッシュもEXEと同じ場所の専用フォルダーへ保存する。設定の別場所への無断保存、関連付け・アプリ用レジストリ変更をしない。
- 自動試験の書込みはEXE配下self-test-dataのみ。本番設定・ユーザー画像を変更せず、ユーザーアプリを無断で停止しない。Stage3参照データは読取り専用: ログ C:\Users\Kunihiro\AppData\LocalLow\VRChat\VRChat、写真 C:\Users\Kunihiro\Pictures\VRChat のYYYY-MMサブフォルダー、OCR用参考データ D:\UserApplications\GitProjects\仕様策定相談\OCR用参考データ。
- 自動試験によるウィンドウ表示の負担を抑える。変更箇所を絞って確認し、全体のDebug／Release試験は最終確認にまとめる。成功後の再実行は関連変更・失敗・未解決の懸念がある場合に限る。verify.cmdの即時終了試験は既定3回とし、追加の反復は終了処理の変更など必要な場合に限定する。
- commit / push / tag / GitHub Releaseは依頼された場合のみ行う。配布は第三者ライセンス通知を同梱する。
- 全構成のEXE名は KuniVRCPhotEditor_vN.M.X.exe とする。版番号はSrc/AppVersion.hから取得する。Stable化の判断はユーザーが行い、Stable配下へ無断でコピー／差替えしない。
